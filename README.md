## ✍️ How I Write These Notes

- **Step by step** — every command and setting in order
- **Explain the why** — not just what to click, but the reason behind it
- **Verified** — each guide is tested on a real machine
- **No secrets** — personal details are replaced with placeholders like `your-email@example.com`
